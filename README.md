# Interview
📘 Top 50 Automation Testing Interview Q&A
🔑 Fundamentals
- What is automation testing?
Automation testing uses scripts/tools to validate applications quickly, reducing manual effort and ensuring regression coverage.
- Difference between manual and automation testing?
Manual testing is human-driven, slower, and error-prone. Automation is tool-driven, faster, reusable, and ideal for regression.
- When should you automate a test case?
Automate repetitive, regression, smoke/sanity, and high-risk scenarios. Avoid one-off or rarely used flows.
- What are the benefits of automation testing?
Speed, accuracy, reusability, CI/CD integration, and reduced cost over time.
- What are the limitations of automation testing?
High initial setup cost, maintenance overhead, and inability to test usability or visual aspects.
🛠 Framework & Tools
- Explain Page Object Model (POM).
Separates UI locators from test logic, improving maintainability.
- Difference between TestNG and JUnit.
TestNG supports parallel execution, data-driven testing, and flexible annotations. JUnit is simpler but less feature-rich.
- What is a hybrid framework?
Combines data-driven, keyword-driven, and modular approaches for flexibility.
- How do you handle dynamic elements in Selenium?
Use explicit waits, dynamic XPath/CSS, and retry logic.
- What is Playwright, and how is it better than Selenium?
Playwright supports multiple browsers, faster execution, auto-waiting, and modern API testing.
